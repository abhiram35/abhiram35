## Featured Projects

### 1. [multi-object-detection](https://github.com/abhiram35/multi-object-detection)
A from-scratch PyTorch object detector implementing anchors, IoU matching, detection loss, NMS, and mAP evaluation without relying on off-the-shelf detection libraries.

### 2. [hackathon26](https://github.com/abhiram35/hackathon26)
A reinforcement learning trading agent built with PPO, combining a fast backend, custom gym environment, and data-driven decision-making workflow.

### 3. [Ml_crop-prediction](https://github.com/abhiram35/Ml_crop-prediction)
A crop yield prediction project using linear regression and a Streamlit interface to turn a machine learning model into an accessible web application.

### 4. [razorpay](https://github.com/abhiram35/razorpay)
A return-fraud detection and auto-response pipeline that combines machine learning risk scoring with business-focused decision routing and auditability.
